# Break notification with AFK awareness

A simple tool, possibly just a C lang script, which shows a break notification after some time of working.

There are a bunch of such tools, but I'm usually missing the ability to show the notification **only** if I actually been working. I often get up from work (e.g. to walk the dogs), leaving my desktop on and I don't want to have a break screen 5 minutes after I'm back only because the timer did not reset when I was AFK.
